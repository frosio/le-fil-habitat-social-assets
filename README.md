# Le Fil Habitat — social assets

Dépôt public d'assets générés pour les publications sociales de Le Fil Habitat.

- Les fichiers sont destinés à être servis par GitHub Pages.
- Aucun secret, token ou fichier `.env` ne doit être ajouté ici.
- Les assets sont organisés par campagne et version.

## URLs publiques

Base GitHub Pages : `https://frosio.github.io/le-fil-habitat-social-assets/`

Exemple :

`https://frosio.github.io/le-fil-habitat-social-assets/instagram/sous-location/slide-01.png`
